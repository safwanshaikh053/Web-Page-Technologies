======Module in node js======
Module in nodejs is a simple or complex functionality organized in single or multiple javascript file can be reused
throughout the nodejs application.


module type :
    core module:
       - it include bare minimum functionality of nodejs.
         these modules are complied into its binary distribution and load automatically when
          nodejs  process start.
         However,we need to import the core module first in order to use it in your application.

 types:
    http:to create http server in node js.
    os:provide info about os.
    path:to handle file path.
    url:to parse the url string.
    fs:to handle file system in computer.
    querystring:to handle url querystring.
    util:to access utility function.

How to use it:
    const variablename=require("modulename")
    __dirname:it provides current directory path.
    __filename:it provide current filepath.



local module:
    local module Are created locally in nodejs application
    these module iclude different functionallity of your application in seperate files and folder
    you can also package it and distribute it via npm so that nodejs community can use it
