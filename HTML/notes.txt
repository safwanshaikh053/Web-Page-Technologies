   =====Callback Function======

   -passing an function name as argument inside another function is called callback Function.
     

     -trim(): it removes spaces between strings.
     -trimStart():  removes  spaces from start of string.
     -trimEnd(): removes  spaces from end of string.

     ES5-ECMA Script 5 -2009

     forEach():   -it call another method for each array.
                  - it do not return any values, it is used to iterate array value only

    
    map():    always returns a new array with the results of the callback function. The original array remains unchanged.


    filter(): it call another once for each array and return new array of those who satisfy given condition.

    every():  it call another once for each array and return true value if all array element satisfy given condition.

    some():   it call another once for each array and return true value if some array element satisfy given condition.

    reduce/reduceRight(): it return array values as a single result, it takes 2 parameter--previousNum, nextNum.
