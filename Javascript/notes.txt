        variables in javascript
          -variable is a container where we store data for temporary purpose.
          -data stored in variable can be changed later.
          -in js we can create variable by using var, let and const keyword.

             let variableName;//syntax variable declaration
             variableName=value; //initialization


        **what is Hoisting in js?
            it is default js behaviour, which moves variable declaration at top.
            to remove this let keyword is used.

        Difference between let, var and const

            var: create a function scope variable.
                 we can redeclare a variable.
                 we can use variable first and then declare it.
            let: it create blocks of variable.
                 it prevent redeclaration of variable.
                 we cannot use variable before declaration of it.
            const: it create block scope constant variable.
                    when we create const variable at sime time we have to initialize it.
                    constant variable value cannot be while Run time.

What is Difference between == and ===
    ==: it will check if the both data are same then return true.
    ===: it will check if the data and data type are the same then return true.

    =================Functions in Javascript==================
        function is a bliock of code which we use to perform particular task.
        it will only execute when it is called.
        it can be use multiple times.


        //default function
        function greeting(){
            return 'Good Afternoon u all';
        }
        console.log(greeting());
        //paramerized function
        function addition(num1,num2){
            return num1+num2;
        }
        console.log(addition(20,70));
        //Anonymous function: A function with no name is called Anonymouos function
        let sub =function (num1,num2){
                return num1-num2;
        }
        console.log("Substraction :",sub(20,70));
        //Arrow function: A function with no name no function keyword is called Arrow function
        let mul=(num1,num2)=>{
            return num1*num2;
        }
        console.log("Multiplication :",mul(20,70));
        //optional parameterized function : in this no need to pass parameter value, optional parameter always write at last
        let fullname=(fname,lname,mname="")=>{
            return fname+mname+lname;
        }
        console.log(fullname("Full Name :",'Safwan','Shaikh'))
        console.log(fullname('Safwan','Mohammed','Shaikh'))//if you want give optional like middle name here then u can , if u don't then there will be no error
        //rest parameterize  function: when we dont know how many parameter are required , in that case we use. here we use spread(...) operator
        let stdList=(...std)=>{
            return std;
        }
        console.log(stdList("Ram","Manish","Aabhas","Swapnil","Junaid"))
