Q. what is difference between let,var and const 
var:
-it create a function scope variable.
-we can redeclare variable 
-we can use variable first and then declare it.

let :
-it create block scope variable 
-it prevent re-declration of variable.
-we can not use variable before declration of it.

const:
-it create block scope constant variable.
-when we create constant variable at same time we have to initialize it.
-constant variable value can not be while run time.

-it return  index of first occurences of searching string.
-it search seach string from right to rileft.

3.search(searchingString):
-it return  index of first occurences of searching string.
-it search seach string from left to right.
-if searching string do not found it return -1 as result.
