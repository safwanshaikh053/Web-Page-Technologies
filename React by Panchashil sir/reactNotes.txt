*useEffect() hook:
it execute only after function component render.
-it takes two parameter 1. callback function, dependency 
syntax  useEffect(()=>{},dependency) 

case1: no dependency value pass , it execute everytime when component render.
       useEffect(()=>{}) 

case2:  dependency value pass as blank array ,it execute only once when component render.
       useEffect(()=>{},[]) 

case3: dependency value pass in array ,it execute once when component render. and execute when state or property value change.
useEffect(()=>{},[state/props]);
